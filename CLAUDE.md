# ldm-report (the unmask.tools website)

Static website for unmask.tools: landing, pricing and checkout pages, account page, docs, templates, press kit,
phrase library and RSS feed. Plain HTML, CSS and JavaScript with no build step. Hosted on GitHub Pages under the
custom domain unmask.tools. **This repository is public: never commit credentials, customer data or internal
notes.**

This folder is also a **git submodule** of the main project repo (`unmask-extension`, folder `report-site/`).
The backend (Supabase functions, Stripe webhook, Cloudflare workers), the extension and the open-items list
`TODO.md` live in that repo, not here.

## Run and preview

```bash
python3 -m http.server 8765      # from this folder, then open http://localhost:8765
```

Pushing to `main` publishes the site (GitHub Pages). There is no staging environment, so check pages locally first.

## Layout

- Pages: `index.html`, `pricing.html`, `checkout.html`, `account.html`, `register.html`, `docs.html`,
  `templates.html`, `tools.html`, `report.html`, `dataroom.html`, `company.html`, `support.html`, legal pages.
- Shared: `nav.js`, `footer.js`, `sitemap.xml`, `robots.txt`, `llms.txt`, `feed.xml`, `CNAME`.
- `press/` (press kit), `sample/`, `stress-test/`, `stubs/` (test pages), `community-phrases.json`.
- `.github/workflows/update-community-phrases.yml`: a weekly bot (Monday 06:00 UTC) regenerates the community
  phrase library and commits to `main`.

## Rules

- **Do not change `CNAME`.** Declaring the wrong host there once caused Google Search Console indexing errors.
- `feed.xml` is generated by `scripts/generate-feed.mjs` in the main repo; do not hand-edit it.
- Checkout links are live Stripe Payment Links; the tier mapping was verified by hand. Check the main repo's
  `TODO.md` before changing `checkout.html` or the pricing wording.
- Keep claims on the pages consistent with the privacy page and the store listing.

## Working across machines

`git pull` before you start (the weekly bot commits to `main`); commit and push when you stop. After pushing here,
update the submodule pointer in the main repo (`git add report-site && git commit` there).
